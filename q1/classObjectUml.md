# SG4 - Understanding Classes and Objects
## Class Name
- Pencil
## Class Description
- My class represents an object used for writing
## Properties
| Property | Data Type | Description |
|---|---|---|
| Color | String | This is the color of the pencil |
| Length | Integer | This is the length of the pencil |
| Brand | String | This is the brand of the pencil |
| isSharpened | Boolean | This is if the pencil is sharp or not |
## Methods
| Method | Description |
|---|---|
| sharpen() | To sharpen the pencil |
| write() | To write something with the pencil |
| erase() | Erase something with the pencil |

## Design Explanation
### Why did you choose this class?
- I chose the pencil because it is the most simple and used object in a school.
### Which property is the most important? Why?
- Definitely the isSharpened property because it shows us if the pencil is ready to write or not.
### Which method is the most useful? Why?
- The write() method is the most useful because the main purpose of a pencil is to write.
